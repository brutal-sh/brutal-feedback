# Contributing feedback

This repository hosts Brutal beta releases and feedback. The [support guide](SUPPORT.md) explains how to report bugs, suggest improvements, or ask for help.

For questions about the in-app **Share stats** option, link to the [Brutal privacy disclosure](https://brutal.sh/help/privacy/#usage-stats).

Use one issue per reported behavior. Add useful context to an existing issue if you find the same problem. Maintainers use labels such as `needs triage`, `bug`, and `enhancement` to organize reports. A maintainer may ask for a minimal example, suggest a workaround, or link a beta that contains a fix.

Help others reproduce issues with shareable examples and respectful, actionable comments. Follow the [code of conduct](CODE_OF_CONDUCT.md) when participating.
