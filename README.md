# Brutal beta feedback

- [Report a bug or crash](https://github.com/jpoindexter/open-pen-feedback/issues/new?template=bug.yml). Search existing reports first. Include the Brutal version, macOS version, and what you expected and saw. Add reproduction steps if you have them.
- [Request a feature](https://github.com/jpoindexter/open-pen-feedback/issues/new?template=feature.yml). Describe what you are trying to do and where the current workflow falls short.
- [Ask a question](https://github.com/jpoindexter/open-pen-feedback/discussions/categories/q-a) or [share general feedback](https://github.com/jpoindexter/open-pen-feedback/discussions/categories/general). Start with the [Brutal Help site](https://open-pen.vercel.app/help/).
- [Report a security vulnerability privately](https://github.com/jpoindexter/open-pen-feedback/security/advisories/new).

Issues and discussions are public. Use a sample document you can share and review
screenshots and diagnostics before attaching them. Keep private designs, account
information, keys and tokens out of public posts.
