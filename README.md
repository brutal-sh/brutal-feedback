# Brutal beta

Download the signed, notarized Apple-silicon Mac beta from [Releases](https://github.com/brutal-sh/open-pen-feedback/releases). See [Getting started](https://brutal.sh/help/getting-started/#download) for installation and checksum verification.

- [Report a bug or crash](https://github.com/brutal-sh/open-pen-feedback/issues/new?template=bug.yml). In Brutal, choose **Help → Report an Issue** to open the same form.
- [Request a feature](https://github.com/brutal-sh/open-pen-feedback/issues/new?template=feature.yml). Describe the goal and where the workflow falls short.
- [Ask a question](https://github.com/brutal-sh/open-pen-feedback/discussions/categories/q-a) or [share general feedback](https://github.com/brutal-sh/open-pen-feedback/discussions/categories/general).
- [Report a security vulnerability privately](https://github.com/brutal-sh/open-pen-feedback/security/advisories/new).

GitHub requires sign-in to submit. Issues and discussions are public. Review screenshots and diagnostics before posting and use a sample design you can share. See [Support](SUPPORT.md) for what to include.
