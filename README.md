# Brutal beta

Download the signed, notarized Apple-silicon Mac beta from [Releases](https://github.com/brutal-sh/brutal-feedback/releases). See [Getting started](https://brutal.sh/help/getting-started/#download) for installation and checksum verification.

If you already have Beta 10 or later, choose **Brutal → Check for Updates…**. Install from the ZIP if you have Beta 9 or earlier.

The Mac beta includes a local MCP server. Open **Settings → MCP** to connect a compatible client. The CLI is available from the Brutal source checkout and requires Bun. See the [MCP and CLI setup guide](https://brutal.sh/automation/).

**Privacy and usage stats.** Beta 16 has usage sharing off. In builds that offer **Share stats**, sharing requires your consent. Change your choice in **Settings → Privacy**. [See what is sent and how long totals are kept](https://brutal.sh/help/privacy/#usage-stats).

- [Report a bug or crash](https://github.com/brutal-sh/brutal-feedback/issues/new?template=bug.yml). In Brutal, choose **Help → Report an Issue** to open the same form.
- [Request a feature](https://github.com/brutal-sh/brutal-feedback/issues/new?template=feature.yml). Describe the goal and where the workflow falls short.
- [Ask a question](https://github.com/brutal-sh/brutal-feedback/discussions/categories/q-a) or [share general feedback](https://github.com/brutal-sh/brutal-feedback/discussions/categories/general).
- [Report a security vulnerability privately](https://github.com/brutal-sh/brutal-feedback/security/advisories/new).

GitHub requires sign-in to submit. Issues and discussions are public. Review screenshots and diagnostics before posting and use a sample design you can share. See [Support](SUPPORT.md) for what to include.
